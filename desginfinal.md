### 4. Detailed Text for Slide 2 Cards

#### Column 1: HOW IT WORKS (Header: `#0284C7` / Light Blue Background: `#F0F9FF`)
* **Instant AI Vision**: Takes a photo or upload and recognizes Indian monuments, temples, forts, and sculptures in under 1 second using multimodal Gemini vision.
* **Bilingual Audio Dossier**: Instantly synthesizes short, ASI-verified historical summaries, architectural styles, untold folklore, and hands-free voice narration in English and Hindi.
* **360° Travel Ecosystem**: Recommends nearby hidden cultural gems (< 5 km), authentic regional food (e.g., traditional thalis, specialty coffee), verified stays, and live navigation.

#### Column 2: PROBLEM-SOLUTION FIT (Header: `#10B981` / Light Green Background: `#F0FDF4`)
* **The Challenge**: Monument signage is often weathered, vandalized, or limited to English/local script, forcing visitors to hire expensive or uninformed guides.
* **The Fix**: Bridges the gap between taking a vacation photo and understanding its profound 1,000-year history with zero friction and zero mandatory app downloads.
* **Better Tourism**: Prevents severe tourist congestion at mega-sites by dynamically routing visitors to mesmerizing, lesser-known heritage places within walking distance.

#### Column 3: INNOVATION & UNIQUENESS (Header: `#F97316` / Light Orange Background: `#FFF7ED`)
* **ASI/UNESCO Verified Truth**: Eliminates AI hallucination through multi-layer verification guardrails cross-referenced against official archaeological records.
* **Hands-Free In-Browser Audio**: Native browser speech synthesizer provides accessible audio narration for children, senior citizens, and visually challenged explorers.
* **Hyper-Local Economy Booster**: Automatically channels tourism revenue directly into the hands of local artisans, folk artists, and authentic traditional food vendors.

```
┌────────────────────────────────────────────────────────┐
│                      TECH STACK                        │
├────────────────────────────────────────────────────────┤
│  [1] FRONTEND SPA       ➔ React 19.0 + TypeScript 5.8  │
│  [2] BUNDLER & STYLING  ➔ Vite 6 + Tailwind CSS v4     │
│  [3] ANIMATION & ICONS  ➔ Framer Motion + Lucide React │

│  [7] BACKEND API        ➔ Node.js + Express REST API   │
│  [8] DATABASE (CLOUD)   ➔ TiDB Cloud Serverless MySQL  │
│  [9] IMAGE SOURCING     ➔ SerpAPI + Google Places API  │
│ [10] CLOUD HOSTING/CDN  ➔ Render + Cloudinary CDN      │
└────────────────────────────────────────────────────────┘
```

#### Detailed Breakdown of Tech Stack Nodes:
1. **Frontend SPA**: React 19 + TypeScript for high-performance reactive UI and type-safe data handling.
2. **Bundler & Styling**: Vite 6 bundler for lightning sub-second HMR + modern Tailwind CSS v4 styling.
3. **Motion & UI**: Framer Motion for fluid card transitions, AR scanning lasers, and Lucide React icons.
4. **Multimodal AI**: `@google/genai` Gemini 2.0/2.5 Flash for multimodal visual recognition and JSON dossier synthesis.
5. **Speech Synthesis**: Native browser Web Speech API (`SpeechSynthesisUtterance`) with rate control and dynamic language toggling (`en-US` and `hi-IN`).
6. **Maps & Visualization**: Leaflet 1.9.4 with Google Maps Roadmap & Satellite hybrid tiles (`mt1.google.com/vt/lyrs=y`) and 3D embeds.
7. **Backend Engine**: Express.js REST API with input sanitization, security guardrails, and error handling.
8. **Cloud Database**: TiDB Cloud Serverless MySQL (port 4000, TLS encrypted) with automatic failover to local JSON persistence (`data/heritage_sites_db.json`).
9. **Visual Sourcing**: Multi-tier pipeline querying SerpAPI Google Images, Google Places, Wikimedia Commons, and Wikipedia.
10. **Hosting & Media**: Deployed on Render Cloud Web Services with Cloudinary CDN media compression (`auto:eco`).

* **Layer 1 (Data Quality)**: Rare monuments lack curated online datasets.
* **Layer 2 (Vision Accuracy)**: Shadows, rain, or obstruction can hinder optical identification.
* **Layer 3 (Network Connectivity)**: Remote hill forts (e.g., Chittorgarh, Kumbhalgarh) often have limited cellular reception.
* **Layer 4 (Factual Trust)**: Potential for commercialized disinformation and generic AI hallucinations.
* **Layer 5 (Language Diversity)**: India's vast linguistic spectrum requires regional language support beyond English.

### 4. Panel 3: `03 STRATEGIES TO OVERCOME CHALLENGES`
* **Sub-Header Pill (Blue)**: *"Our engineering ensures reliability, factual trust, and resilience."*
* **Visual Representation**: **Orbiting Hexagonal Nodes Surrounding Central Shield Badge**:

* **Central Core Badge**:
  ```
  ╔═════════════════════════════╗
  ║      RELIABLE • ACCURATE    ║
  ║         RESILIENT           ║
  ╚═════════════════════════════╝
  ```
* **5 Surrounding Strategy Nodes**:
  1. **Dual-Tier Database Failover**: TiDB Cloud MySQL continuously mirrors to local file storage (`data/heritage_sites_db.json`), guaranteeing zero downtime even if the database is unreachable.
  2. **Multi-Source Image & Data Validation**: Cross-verifies facts against Archaeological Survey of India (ASI) records, Wikipedia historical archives, and Google Places photography.
  3. **Strict Query Sanitizer Guardrails (`server/validator.js`)**: Enforces physical landmark verification, instantly rejecting non-monument items or inappropriate inputs.
  4. **Lightweight PWA Offline Caching**: Browser Service Workers and LocalStorage cache scanned dossiers so tourists can replay audio narration without continuous internet.
  5. **Human-in-the-Loop Admin Portal**: Cryptographically protected portal (`ADMIN_SECRET_KEY`) allows ASI officials, tourism boards, and teachers to audit, edit, and approve entries.
